    TriggerHandlerBypassPermissionTest

    Tests for the BypassTriggerHandlers custom permission of TriggerHandler.
    The test creates a test user and gives it the permission through a permission set. Salesforce allows no DML on permission set objects in a parallel test class, so these tests are in their own class without isParallel.

    TriggerHandlerBypassPermissionTest Methods

    • bypassPermissionSkipsEveryHandler ()
      A user with the BypassTriggerHandlers permission runs no handler: no context method, no andFinally(), and no loop count. The code bypass checks do not report it, and code cannot clear it.
    • newHandler ()
      Creates a test handler that runs as if a trigger fired after update.
    • newUserWithBypassPermission ()
      Creates a test user with the profile of the running user, and gives it the BypassTriggerHandlers custom permission through a new permission set.
      The setup runs in system mode, so that it does not depend on the rights of the user who runs the tests. So this method suppresses FlagSystemMode. The permission check under test runs later, in System.runAs() for the test user.
