    TriggerHandlerTest

    Tests for the TriggerHandler base class.
    Each test proves 1 behavior. Most tests create their handler with newHandler() and read the call log.
    No real trigger runs in these tests: setTestContext() gives each handler its trigger operation. The sample tests, which are outside the package directory, run the real trigger.
    NcssCount is suppressed. The class has 1 test for each behavior of the framework, the bypass and loop counter registries too, so it is large by design.
