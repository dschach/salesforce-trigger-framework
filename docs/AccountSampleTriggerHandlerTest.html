    AccountSampleTriggerHandlerTest

    Tests for the sample handler and the sample trigger. Each test proves 1 behavior. All tests but the constructor test use real DML.
    AccountSampleTriggerHandler.finishedOperations is the call log. andFinally() adds each operation that the handler finished.
    The test DML and the queries that read the results run in system mode, so the class suppresses FlagSystemMode. The tests set up and check the data directly. The access under test is the access of the handler, which uses system mode on purpose.
