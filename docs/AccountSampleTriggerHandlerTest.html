    AccountSampleTriggerHandlerTest

    Tests for the sample handler and the sample trigger. Each test proves 1 behavior through real DML.
    AccountSampleTriggerHandler.finishedOperations is the call log: andFinally() adds each operation that the handler finished.
    The test DML and the queries that read the results back run in system mode, so FlagSystemMode is suppressed for the class. The tests set up and check data directly: the access under test is the handler's own, which states system mode on purpose.
